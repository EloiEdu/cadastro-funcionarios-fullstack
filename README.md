Sistema de gerenciamento de funcionários desenvolvido como projeto de estudo para aprofundar conhecimentos em desenvolvimento Full Stack, aplicando boas práticas de arquitetura, APIs REST e integração entre frontend e backend.

📋 Sobre o projeto

A aplicação permite realizar o gerenciamento completo de funcionários utilizando operações de CRUD (Create, Read, Update e Delete).

O projeto foi desenvolvido com separação entre frontend e backend, utilizando uma API REST construída com Fastify e persistência dos dados em PostgreSQL.

✨ Funcionalidades
Login (estrutura inicial)
Listagem de funcionários
Cadastro de funcionários
Edição de funcionários
Exclusão de funcionários
Integração entre Angular e Fastify
Persistência em PostgreSQL
API REST
